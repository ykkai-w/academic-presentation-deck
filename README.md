# Academic Presentation Deck

A Codex skill that turns a paper, presentation template, and speaking constraints into editable submission and preparation decks with speaker notes, cross-review, and validation checks.

## Install

```sh
git clone https://github.com/ykkai-w/academic-presentation-deck.git ~/.codex/skills/academic-presentation-deck
```

## Use

Invoke `$academic-presentation-deck` with your paper, template, talk length, and submission constraints.
